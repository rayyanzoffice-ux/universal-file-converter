# Contributing

Thanks for improving Universal File Converter!

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make small, accessible, browser-only changes. Never add file uploads or analytics that inspect content.
4. Run `npm run lint` and `npm run build`.
5. Open a pull request explaining the change and how it was tested.

Report security concerns privately to the maintainers rather than in a public issue. By participating, you agree to follow the Code of Conduct.
